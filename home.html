Mic Needs a Web Server
You're opening this from Downloads — Chrome blocks mic access for local files. Host it online in 2 minutes (free) and the mic will work perfectly.

📱 Android only (no computer needed):

2. Point it to Downloads → tap Start
3. Open the http://192.168.x.x:8080 link in Chrome
